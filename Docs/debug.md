### Ghidra addresses must be rebased for Frida
KEYWORDS: ghidra, address, rebase, PE, image base, guard page, access violation, ptr
SOLUTION: Ghidra VAs use the PE preferred image base from the disk file (0x00400000 for

runtime load address, so you get rebaseOffset=0 which is wrong.

`rebaseOffset = runtimeBase - 0x00400000`. See FridaReference.md for the full pattern.
Using ptr using ghidraAddr directly causes "guard page was hit" or "access violation".
